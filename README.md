# OSRS Slayer Task Lookup

A fan-made, OSRS-styled lookup tool for efficient ironman slayer from levels 50-99.
Pick your level bracket, type your task (nicknames work - "gorillas", "nechs", "kraken"),
and the slayer master for that bracket tells you whether to **do**, **skip**, or **block** it,
with notes on gear, unlocks, and boss detours. Tick off blocks as you buy them in game
and the tool remembers them (localStorage).

**[Open the tool](https://jb-darnic.github.io/osrs-slayer-lookup/)** (if GitHub Pages is enabled) or download `index.html` - it is fully self-contained and works offline.
